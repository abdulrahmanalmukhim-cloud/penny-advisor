# Penny Advisor 📈

لوحة عربية متجاوبة لتحليل أسهم البيني ستوك الأمريكية. النسخة الحالية MVP ببيانات تجريبية، وتعرض السعر والحجم وRVOL وVWAP والمستويات ومخاطر SEC وسيناريوهات الحركة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

> تنبيه: المشروع تعليمي وليس نصيحة مالية. لا تُضاف مفاتيح API إلى كود المتصفح؛ عند ربط بيانات حقيقية استخدم Server Routes ومتغيرات البيئة.
